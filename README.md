# PlusVibe Balance

Два способа смотреть остаток и расход PlusVibe API:

- `pv.py` — консольная сводка (баланс, расход за сегодня и за месяц, число запросов);
- `gnome-widget/` — индикатор остатка прямо в верхней панели GNOME Shell (45–50).

Оба используют один и тот же ключ `sk-pv-...` из одного и того же файла —
`~/.config/plusvibe/key.txt` (или `key.txt` рядом со скриптом).

> **Про сервис и ссылку.** Это не официальный клиент PlusVibe, а моя личная обвязка:
> я сам пользуюсь PlusVibe и написал её под себя. Если решите завести там аккаунт —
> [можно по этой ссылке](https://plusvibeapi.ru/?ref=TGMRF4YP). Мне за это начисляют
> бонус, вам это ничего не стоит: ни на цену, ни на работу скрипта ссылка не влияет.
> Ничего покупать не нужно — `pv.py` и виджет целиком работают и без регистрации
> по чьей-либо ссылке.

## Ключ

Ключ PlusVibe хранится только локально и в репозиторий не попадает. Положить его можно:

```
mkdir -p ~/.config/plusvibe
printf '%s\n' 'sk-pv-ваш_ключ' > ~/.config/plusvibe/key.txt
chmod 600 ~/.config/plusvibe/key.txt
```

Либо переменной окружения `PLUSVIBE_API_KEY`. Формат файла — просто строка с ключом
либо `PLUSVIBE_API_KEY=sk-pv-...` (строки с `#` игнорируются).

## Консоль: pv.py

```
python3 pv.py            # человекочитаемая сводка
python3 pv.py --write    # обновить status.txt + короткая строка статуса
python3 pv.py --json     # сырой JSON
python3 pv.py --raw      # только ответ /api/key/usage
```

Порог низкого баланса — переменная `PLUSVIBE_LOW_THRESHOLD` (по умолчанию 100 ₽).
Базовый адрес API переопределяется `PLUSVIBE_BASE` (по умолчанию `https://plusvibeapi.ru`).

## GNOME-виджет

```
cd gnome-widget
./install.sh
```

Индикатор показывает `PV <остаток> ₽`; при остатке ниже порога — красным; без ключа —
`PV: ключ?`. Клик открывает меню с расходом за сегодня и месяц.

Подробности установки и диагностика — в `gnome-widget/README.md` и `gnome-widget/doctor.sh`.
Требуется GNOME Shell 45–50 (ESM-расширения) и утилита `zip` для установки.

## Требования

- Python 3.10+ для `pv.py` (только стандартная библиотека).
- `curl` и `zip` для виджета.
